Preemption Mode
| Option                           | Valeur                                    | Description                                                                                |
|----------------------------------|-------------------------------------------|--------------------------------------------------------------------------------------------|
| Preemption Mode                  | ( ) Preemptible Kernel                    | Permet une préemption du noyau, utile pour des environnements nécessitant de bas latences. |
|                                  | (X) Scheduler controlled preemption model | Contrôle de la préemption par le scheduler, offert par défaut dans les noyaux modernes.    |
